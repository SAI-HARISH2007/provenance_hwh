# Incident Report: orders-api Failure due to Disk Full

## Summary
On 2026-08-30 at 03:12 UTC, a P1 alert fired for `orders-api` with an order creation failure rate of 58%. Investigation revealed that PostgreSQL writes were failing due to the database disk being completely full (100% utilization), caused by massive log growth after `log_min_duration_statement=0` was enabled earlier.

## Timeline
- **2026-08-30 01:02 UTC**: Config change `log_min_duration_statement=0` enabled on PostgreSQL for slow-query investigation.
- **2026-08-30 02:45 UTC**: Inventory and orders API requests start failing with database write and file extension errors.
- **2026-08-30 03:12 UTC**: P1 alert fires for `orders-api` order creation failure rate.
- **2026-08-30 03:15 UTC**: Investigation confirms disk usage is at 100% due to PostgreSQL log files reaching 96GB and growing at 1.1GB/min.

## Root Cause
`disk_full` - PostgreSQL disk volume `/var/lib/postgresql` filled up to 100% capacity due to excessive log output generated by setting `log_min_duration_statement=0` (logging every single query). This caused PostgreSQL to throw `53100` / `could not extend file` I/O errors during write operations.

## Evidence
- **Logs**: `orders-api` logs showed `insert failed: could not extend file "base/16384/2619"` errors. `inventory-api` logs showed `reservation write failed: database I/O error`.
- **Database Probe**: `run_probe db postgres` reported `41/100 connections; writes failing ERROR 53100 disk_full`.
- **Disk Probe**: `run_probe disk postgres` reported `/var/lib/postgresql: 100% used (200G/200G); /var/lib/postgresql/log = 96G, growing 1.1G/min`.
- **Config History**: `recent_changes` showed `log_min_duration_statement=0` was enabled at 01:02 UTC.

## Proposed Remediation
`free_disk_space` on `postgres` (specifically truncating/rotating the overgrown PostgreSQL logs and reverting `log_min_duration_statement`).

## Follow-ups
1. Revert `log_min_duration_statement` to its previous setting or a higher threshold (e.g., `250` or `1000`ms).
2. Set up log rotation and disk usage alerts for the PostgreSQL storage volume.
