What memory changed

AccuracyUnchanged on this benchmark. The memoryless agent already solves these; memory did not add or remove a correct verdict. First probeOn repeats (s13, s17) the agent went straight to the probe that settled the earlier incident. ContextRecall adds 1–3k tokens per incident for the memory block; the gate adds one call when it fires. SafetyA remembered rollback that would have been wrong on s15 is blocked until re-verified. Live runs never took the bait; the offline replay shows the gate firing. Open gaps16 (poison message) is wrong in every configuration; recall found nothing because the earlier record is worded too differently.

Source: eval/results/fair-* and pair-* on gemini-3.5-flash-lite. Reproduce with make memory-eval.
